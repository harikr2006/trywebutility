  • Regex Tester — test regular expressions with live match highlighting, capture group display, and global/case-insensitive flags.
  • CRON Expression Tester — validate cron expressions and preview the next 10 scheduled run times in human-readable format.
  • Semver Validator — parse and validate SemVer 2.0 strings (MAJOR.MINOR.PATCH), check pre-release tags, and compare two versions.
  • JSON Path Tester — query JSON data with JSONPath expressions and inspect matching nodes.
  • Diff Checker — compare two text blocks side by side with character-level diff highlighting and line numbers.

Security & analysis tools

  • Password Strength Checker — analyze entropy, character variety, and estimated crack time for any password.
  • HTTP Status Reference — quick reference for all HTTP 1xx–5xx status codes with descriptions and common use cases.
  • IP Subnet Calculator — compute network address, broadcast address, host range, and CIDR notation for any IPv4 subnet.
  • Chmod Calculator — convert Unix file permissions between symbolic (rwxr-xr-x) and numeric (755) representations.
  • Color Contrast Checker — check WCAG 2.1 AA and AAA contrast ratio for any foreground/background color pair.

Text analysis tools

  • Readability Score — analyze text with Flesch-Kincaid, Gunning Fog, and SMOG readability indices to target the right audience.
  • Word & Character Counter — count words, characters, lines, sentences, and estimated reading time for any text.
  • Byte Size Calculator — compute the exact UTF-8 byte size of any string — useful for validating API payload limits.
